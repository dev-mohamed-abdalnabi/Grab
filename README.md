# Grab

## العربية
مدير تحميلات ووسائط لأندرويد لتنزيل الملفات والوسائط وتشغيلها ومشاركتها، مع دعم قوائم الانتظار والمكتبة المحلية.

## English
An Android media downloader and player for downloading, organizing, playing, and sharing media with queue and local library support.

## Build
يتم بناء APK من خلال GitHub Actions. مفاتيح التوقيع محفوظة في GitHub Secrets ولا توجد داخل المستودع.

The release APK is built through GitHub Actions. Signing credentials are stored in GitHub Secrets and are not included in the repository.
